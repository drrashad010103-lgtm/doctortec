# خريطة الميزات — من PHP إلى VB.NET

**المصدر:** 100 صفحة في `D:\rs_pharmacy\app\pages`
**الهدف:** تحويل كل شاشة قديمة إلى وحدة واضحة في تطبيق Windows Forms، مع تحديد
ما يُبنى أولًا، وما يُدمج، وما يُؤجَّل، وما يُلغى.
**القاعدة:** لا تُنقل شاشة لمجرد وجودها. كل سطر أدناه له قرار صريح.

| الموجة | عدد الصفحات | أمثلة |
|---|---:|---|
| 0 (بنية تحتية) | 6 | `login`, `logout`, `snapshot`, `backup`, `restore`, `migrate_in` |
| 1 (MVP) | 36 | البيع، الشراء، الأصناف، المخزون (عرض)، الورديات، التقارير الأساسية |
| 2 (مالي/علاقات) | 34 | العملاء، الولاء، الكوبونات، الخزائن، القيود، الجرد |
| 3 (فروع/مزامنة) | 10 | المزامنة، التحويلات، الفروع، شاشة المتابعة، إقفال السنة |
| 4 (تكاملات) | 11 | HR، الرواتب، EasyOrders، واتساب، البنوك |
| ملغاة/مدمجة | 3 | `sale.php`, `msale.php`, `buy.php` |

> بعض صفحات الموجة 3 معلَّمة ⛔ لأنها **تُستبدل** لا تُنقل (`sync.php`,
> `sync_in.php`)؛ الموجة تشير إلى وقت بناء البديل.

## 16. ما لا يُنقل إطلاقًا

| العنصر | السبب |
|---|---|
| `table_swap` / `table_upsert` | LWW وفقدان بيانات |
| `REPLACE INTO` للفواتير | يحذف ثم يدرج = فقدان تاريخ |
| DDL من الويب (`migrate_in`) | خطر أمني وتشغيلي |
| `double` للحقول المالية | فروق تقريب |
| `IS_Buy` + `proc_type` المزدوج | مصدر أخطاء |
| `item_bal` كمصدر حقيقة | يجب أن يكون Cache من `stock_moves` |
| `app/src` | طبقة ميتة |
| `sand*`, `tawla*` | إرث غير مستخدم |
| `twreed_srf*`, `*_bak_*`, `_orphan_sub` | نظافة بيانات |
| توافق كلمة المرور النصّي | ثغرة |
| `root` بلا كلمة مرور | ثغرة |
